Finding your way in Settings

  1. Settings has eight main sections. Songs & Setlists: Create a song, Import songs & projects, Songs & setlists, Autosync & web editor, Sync & sharing, Backup & restore, Setlist design, Song PDF design and Profile & document details.
  2. Audio: Audio files, Audio & playback, Tempo & metronome, Practice and Tuner. Mixer: Mixer, Mixer settings, Song loudness and Mixer cues & shows. Lyrics & Chords: Lyrics & chords, Chord diagrams and Capo & key.
  3. Appearance: Theme & colours and Fonts & text. Controls: Buttons & fullscreen, Scrolling & sync, MIDI & pedals and External display. Planning: Band & members, Calendar, Venues and Packing list. Help & Info opens this manual and Ask BenKen.
  4. Every page has Settings at the top left to go back one level and Done at the top right to close. Use Search settings on the Settings home page to find a function. SHOW INFO adds short explanations on each page.
  5. This manual matches BenKen web V26.276 and the native app V27.55. Native-only features need the installed BenKen app; Browser features work in any supported browser.

Chord sheets, size and playback

  1. A− / A+ scales lyrics and chord sheets. Adjust the independent 18–192px song title under Fonts & text with − and +; the title also appears in fullscreen.
  2. Use Add chord chart demo in Lyrics & chords for an original practice song with audio, 16 bars and four synced regions. Opening Edit chord chart without a saved chart creates a suggested bar chart from the existing lyrics and chords. Generate from lyrics can rebuild the draft; Restore previous draft undoes generation. Synced region lengths and tempo set bar counts when available; chord positions are estimated. Without timing, one bar per chord is suggested. Listen and correct the chart before saving. In Edit chord chart, choose Listen & edit to play the saved song while changing an isolated draft. The current bar and beat follow exact synced regions and tempo. Edit current bar selects its written chords; Play selected bar returns to that bar. Save keeps the chart and Cancel discards changes. Save a new song with audio before listening here.
  3. Chord-sheet columns adapt to text size and available width. Add explicit | bar lines in Edit chord chart; a copied unmetered chord sequence can show its current section but cannot show an exact current bar.
  4. Follow synced bars uses exact Sync lyrics starts or enabled REAPER regions. Match the section names in the chart. Estimated section starts do not drive playback marking.
  5. The current bar follows song BPM and beats per bar from Tempo & metronome. Imported REAPER tempo changes are followed when available. Confirm BPM, meter and region starts against the recording. Write bars in played order; repeat signs are not unfolded automatically.
  6. Enable Scroll to move the reading view with the active bar. Pausing keeps the current position; seeking and region jumps update the marker.
  7. Lyric section labels use a coloured frame, matching chord-sheet headings. Settings icons follow the theme accent.

Create a song and import files

  1. Open Settings → Songs & setlists → Create a song. Add a title, open Edit lyrics to paste or write lyrics and chords, or choose Import lyrics / ChordPro. Select audio files and Save song to keep the complete song.
  2. Create a song has Settings at the top left: it closes the song without saving and returns to the Settings menu. Cancel and × do the same; only Save song keeps the song.
  3. Edit lyrics is the same full-screen editor used for saved songs. Its Chords, sections & text colour tools include remembered chord buttons, section shortcuts and selection colours. Save there returns lyrics to the song draft; Cancel keeps the previous draft. Save song commits the entire song. Optional artist, key, tags and Song color are under Song details.
  4. The main form shows a read-only lyrics preview. Tap it or Edit lyrics to open the editor. Song-color presets are shared by Create and Edit song: choose a swatch, use a custom colour, or select No color. Cancelling the song does not change the saved library.
  5. Audio files are copied only when Save song is pressed. Cancel discards pending selections. If the audio import fails, the saved song remains in the editor with its selected files so saving again retries that same song.
  6. Use Settings → Audio files to add tracks to the selected song. With an empty library, this opens the song editor first. Lyrics / ChordPro remains a separate import option for text files.
  7. Import project opens a complete BenKen .benken song or library package directly from this menu and shows its result here. A library replacement still asks for confirmation and backs up the current text library first. REAPER export packages retain their track/region selection workflow.

Controls, import & mixer display

  1. Settings → Import songs & projects: import audio files, import/update a REAPER project, or add lyrics / ChordPro. Audio files are added to the selected song.
  2. Settings → Buttons & fullscreen: open Control bar & side shortcuts, Fullscreen, Playback & lyrics or Available buttons. Mute group names are edited in Mixer settings → Mute groups. SAVE CONTROLS applies the choices.
  3. In Control bar, show or hide Metronome, Tuner and Capo & Key independently. The left shortcuts pack together without empty gaps. Metronome opens Tempo & metronome.
  4. Use the small arrow above the bottom control bar to collapse or expand its timeline and song information. The playback buttons stay visible. Side controls remain buttons only.
  5. Show next when scrolling is under Lyrics & chords and Controls → Playback & lyrics. It keeps the next-song label visible after the original label scrolls away.
  6. If Play is unavailable, tap it for Check Stereo / USB and the current audio problem. This does not change routing or start audio.
  7. Mixer settings → Mixer display: Show master fader and Normal / Narrow / Extra narrow mixer. Song and Master faders use the same size as the track faders.
  8. Mixer settings → Track EQ or Master compressor: effects are optional and off until checked on. Old saved values are kept but not automatically activated after the stability bypass. Track EQ and master compression work in Browser and in the native app. Do not change engine during playback.

Band & planning

  1. An administrator publishes rehearsals and concerts, invites members by link and checks attendance replies. Contracts and fees are visible only to administrators. New users need working sign-in email delivery.
  2. Open Settings → Planning → Band & planning. Sign in with your own email, create a band or paste an invitation link. The creator is administrator; invited users join as members.
  3. Create an event in Calendar, attach setlists, songs, venue and packing list, then publish it from Band & planning. Shared lyrics and setlists are snapshots; share audio separately.
  4. Members refresh the band page and choose I CAN COME, CANNOT COME or UNSURE. They must confirm again after an event is replaced. Cancelled events remain visible. Automatic email and push reminders are not sent.
  5. Contracts and fees are stored separately with administrator-only access. Profile & document details supplies local PDF and contract information; it is not the band sign-in page.
  6. Packing checks are shared for published band events. Members check assigned or unassigned items; administrators add or remove them. Local lists remain separate until shared.
  7. Requires the Supabase band setup and working email delivery. Sign-in state lasts for the app session. Invitation links expire after seven days and can be used once.

Ask BenKen

  1. Open Settings → Help & Info → Ask BenKen. Enter a question or feature name. Answers and instructions are displayed in English.
  2. Results are matching sections from the included user manual, with steps and shortcuts to settings. Search uses words and synonyms; it does not generate AI answers.
  3. Choose Read in manual for the complete section. If no result matches, try a shorter feature name or browse the manual.
  4. Ask BenKen works offline. Questions are not sent to a server or stored as conversation history. Help does not change settings or start playback.

Profile & documents

  1. Settings → Profile & document details stores your band name, logo and contact information locally and includes them in BenKen backups. Contact and bank details are used for contract drafts; song and setlist PDFs use the band name and optional logo.
  2. Song PDF design and Setlist design offer previews, themes, fonts, sizes and A4/Letter. DOWNLOAD PDF creates an image-based PDF with Unicode support, without audio or searchable text. PDFs show the original song key and chords; capo display and playback transposition do not change them.
  3. Choose Warm Paper or another skin under Theme & colours → App skin. Saved personal colors are retained; reading colors are adjusted for contrast on the light background.

Getting started

  1. BenKen Stage Pro combines a song library, audio tracks, lyrics, chords and setlists on Mac, iPad and iPhone. Native features require the installed BenKen app (current version V27.55).
  2. Open the Setlist button at the lower left. Choose LIBRARY to find, add or edit songs, or SETLIST for the playing order.
  3. The buttons at the lower right open Settings, Controls settings, Mixer and show/hide the playback bar. The extra Controls settings shortcut is optional.
  4. A new installation does not automatically contain your audio files. Import songs or restore a full backup with audio before playback. With Autosync, song details and setlists arrive from your other devices, but audio files do not.

Song library & editing

  1. LIBRARY contains all songs. Search by title, artist or tag, or browse artists, tags and recently opened songs.
  2. ADD SONG creates a song. Enter its title, artist, key and lyrics. EDIT SONG opens the selected song; SAVE SONG saves changes.
  3. Use tags for rehearsal songs or genres. A song color helps identify the song in the library and setlists.
  4. Manage audio in Mixer settings → Audio & files. Deleting a song and deleting its audio tracks are different actions. Make a backup before a major cleanup.

Setlists

  1. Open the Setlist button at the lower left (or Settings → Songs & setlists) and create a set. Use + ADD SONGS to select songs. Selection order becomes the playing order.
  2. Move entries up or down to change their order. A song may appear more than once, for example as an encore.
  3. NEXT shows the following song; END OF SET appears after the last entry. Removing an entry from a setlist is different from deleting a song from the library.
  4. Autoplay can be disabled globally or controlled per entry. Test the complete order before a show. Transitions are not guaranteed to be gapless.

Import from REAPER

  1. Open Settings → Import songs & projects, or Mixer settings → Audio & Files → IMPORT / UPDATE FROM REAPER. Choose the correct export and check which song will be updated.
  2. Select the tracks to import. UPDATE SONG updates the selected song; ADD AS NEW SONG creates another entry. Use update when replacing an earlier export.
  3. REAPER regions can supply sections and timing. Avoid overlapping section regions in a single-song export.
  4. Source files may stay in named song folders. The concert sync folder is a separate transfer folder, not the REAPER source folder.

Audio & Files

  1. Open Settings → Audio files, or select the song and open Mixer settings → Audio & files, to add tracks, replace files or inspect file details. Only one Settings and Done row is shown: Settings returns to the Settings menu (or Mixer settings), Done returns to the mixer.
  2. IMPORT / UPDATE FROM REAPER, Audio files and Relink missing audio are at the top. Lyrics only · Use without audio marks a song that has no tracks on purpose.
  3. REPLACE FILE links a new local audio file. DELETE removes one track; Delete all tracks applies to the song’s audio tracks. Check the selected song before removing tracks.
  4. Missing-file warnings identify the song and track. Reimport the song, use REPLACE FILE or Relink missing audio, or restore a backup containing the audio. Show missing files & warnings and Warn on startup control the warnings.
  5. Connecting a mixer or audio interface does not restore missing files. Autosync does not copy audio between devices. Hide warnings only when you already know which files are missing.

MIDI commands in lyrics

  1. Choose the output once: Settings → MIDI & pedals → MIDI CLOCK OUTPUT → choose your MIDI device or MIDI interface. Commands use the same output as MIDI Clock, even when the clock is off. Use the Native audio engine in the installed app.
  2. Add a command: press and hold a lyric line → MIDI COMMAND, or press + MIDI in the control bar (add it under Controls → Available buttons). The command is placed in the lyrics below that line and shown as a blue MIDI tag. Tap the tag to edit or delete it.
  3. Choose CC (Control Change), PC (Program Change), Note, Start, Stop or Continue, the number, value and channel. Or press LEARN and press the pedal or button on your MIDI device. TEST sends the command now.
  4. When it is sent: At the start of this section sends it when playback reaches the section heading above it; above the first heading means when the song starts. At a time sends it at an exact point such as 1:32. Sections need REAPER regions or SYNC LYRICS timing.
  5. Loopers and effects: on the MIDI device, link a CC number (for example CC#80) to a function such as record/play, stop or all start/stop, and use the same MIDI channel. Then add CC 80 with value 127 in BenKen. Example, BOSS RC-600: MENU → ASSIGN, SOURCE CC#80, TARGET TRACK1 REC/PLAY.
  6. You can also type the lines in EDIT LYRICS: {midi CC 80 127: Loop 1 REC}, {midi PC 5}, {midi STOP}, {midi @1:32 CC 81 127 ch 2}. Values are 0–127, channel 1–16.
  7. Starting in the middle of a song sends only the commands after that point. Settings → MIDI & pedals can turn sending or showing MIDI commands off.

Find duplicates

  1. Open Settings → Songs & setlists → FIND DUPLICATES. Matching titles and artists are grouped regardless of capitalization and extra spaces.
  2. These are possible duplicates. Compare key, audio tracks, lyrics, notes and setlist references before choosing a copy.
  3. Choose KEEP for the correct version and REMOVE THIS COPY for the other. The confirmation explains that setlists will use the retained song.
  4. Lyrics and mixer settings are not merged. Audio files are not deleted. UNDO LAST REMOVAL can restore the last removal in the same session if the library has not changed since.

Choose an audio engine

  1. Open Settings → Audio & playback and choose Browser or Native. Native requires the installed app; Browser uses the web audio engine.
  2. Stop playback before switching engines. Switching reloads the app. Wait for preparation to finish before pressing Play.
  3. PREPARING means audio is being prepared. READY briefly confirms completion. Investigate errors before live use.
  4. Analysis displays differ between engines. An unavailable waveform in Native does not by itself mean audio cannot play.

Stereo & USB outputs

  1. PRACTICE / STEREO mixes tracks to stereo outputs 1–2, including click if enabled. LIVE / USB uses separately assigned output buses.
  2. Check buses and output numbers in Mixer settings. On a digital mixer, patch the correct USB returns to the mixer channels you intend to use.
  3. Use TEST AUDIO OUTPUTS at a low level to check routing. App meters show signal before the physical output; they do not prove sound is reaching the speakers.
  4. A backup Mac can be synchronized without being connected to a mixer or audio interface. Check which device and outputs will actually provide audio.

Mixer, buses & mute groups

  1. Choose an output bus directly from the bus field at the top of a track in Mixer → Tracks. The list shows bus names and USB outputs. Routing is also available in Track settings. Stop playback before changing routing.
  2. The click (metronome) strip in the mixer has its own bus field. Choose the click output bus there with playback stopped; the choice is saved with the song’s click settings, the same as Metronome output bus in Tempo & metronome.
  3. TRACKS controls individual tracks. Buses organize outputs. MUTE GROUPS let you mute or unmute several tracks together.
  4. Give tracks and groups clear names. Use SAVE NAMES or the relevant Save button when shown.
  5. Fader 0 dB is the original level. Check saved mute groups before a concert.
  6. Track EQ and the master compressor require explicit activation. Track EQ and master compression work in Browser and in the native app. A saved value alone does not mean an effect is active.

Tempo & transposition

  1. Change tempo in the song’s tempo/audio settings. Check the original BPM before choosing a target tempo.
  2. Audio transposition supports −2 to +2 semitones in this version. Stop the song and wait for preparation after changes.
  3. Choose which tracks follow transposition. Drums and click normally keep their original pitch. The native app supports up to eight transposed tracks.
  4. View only in Capo & Key changes the displayed chords without changing audio. Chords & audio changes both within the supported range.

Capo & Key — song key

  1. Open the # button above Setlist or Settings → Capo & Key. Both open the same editor and saved values.
  2. Song key offers a chromatic wheel or circle of fifths, plus/minus and chord previews. Choose Auto, ♭ or ♯ for note names.
  3. USE TRANSPOSE applies your choices. SAVE CHORDS AS rewrites the stored chords and keeps up to five previous versions.
  4. Previous chord version restores earlier chords while retaining current capo positions. RESET resets the editor draft.

My capo & Bandmate capo

  1. My capo determines the chord shapes displayed in lyrics. For a song in Cm with My capo at fret 3, the shapes become Am while the song key remains Cm.
  2. Bandmate capo is only a reminder of the other player’s capo position. It does not change the song key, lyrics or audio, and does not display their chord shapes.
  3. Example: song key Cm, Bandmate capo 3 and My capo 0 displays Cm in lyrics. Your bandmate can play Am shapes with capo 3.
  4. Use the key wheel for My capo and fret numbers 0–12 for Bandmate capo. Saving the bandmate position changes that reminder only. Names can be customized.

Lyrics, chords & diagrams

  1. Choose Lyrics, Chords or Both under Lyrics & chords. Text size, title size, section headings, fonts and Bold lyrics are under Fonts & text, using − and + steppers.
  2. Write chords in square brackets, such as [Cm] or [G7]. Add headings with INTRO, VERSE, CHORUS and the other section buttons.
  3. Enable chord diagrams under Chord diagrams and choose position and size, including Extra small. Only available verified shapes can be shown.
  4. Region colors can follow REAPER or Theme & colours. Skins change menus and buttons while retaining personal text and track colors.

Autoscroll & section timing

  1. Open Settings → Scrolling & sync. Start autoscroll manually or link it to playback. Adjust scrolling speed with − and + or type a value.
  2. Sync scroll to song duration uses the song length. Check timing and readability during a complete playback.
  3. Use SYNC LYRICS for section timing. REAPER imports with valid regions can also provide timing.
  4. If a section says timing needed, it has no usable start time. Set its timing before expecting a tap on the heading to start playback.

Practice mode & count-in

  1. Practice controls playback from regions and count-in before regions. Count-in before the whole song also works with Practice off, for live use and rehearsal.
  2. Open Settings → Tempo & metronome. Check BPM, beats per bar and Count-in before song. Choose the number of bars and enable Audible count-in for a click.
  3. Check Metronome output bus and Click level (the bus can also be chosen on the click strip in the mixer). In LIVE / USB, patch the click bus to the intended interface or mixer channel. Also test PRACTICE / STEREO.
  4. Use SAVE CLICK SETTINGS when shown. Play counts the selected bars before the song starts. Continue metronome with backing tracks controls the click afterwards.
  5. Add Count-in to Controls for a shortcut. Metronome flashing appears in the header around the app name in your selected color. Metro flash switches it on or off.

Buttons & fullscreen

  1. Open Settings → Buttons & fullscreen → Available buttons to choose actions, labels and order. SAVE CONTROLS applies them.
  2. Control bar opens its choices directly. Choose Bottom, Left or Right. Buttons only hides extra information; Icons only hides labels; Wrap buttons allows additional rows.
  3. Large live buttons shows Play and Next without replacing Available buttons. Switch it off and save to return to your configured buttons. Side live buttons use the usual side-button size.
  4. Fullscreen can show the next song and keep controls visible. The bottom-right Controls button shows or hides the playback bar.
  5. Choose Tuner in an available button slot and save. It opens and starts when tapped. Stop playback before tuning.

Tuner

  1. Open Settings → Tuner, a Tuner button in Controls or the shortcut above Capo & Key. The tuner starts when opened. Stop playback before tuning.
  2. Allow microphone access when asked. Play one string or note at a time. The display shows note, octave, frequency and cents deviation.
  3. Green indicates a note close to the target pitch. Display smoothing reduces flicker. Short analysis windows serve guitar and voice; longer windows serve low bass notes.
  4. Done, closing the tuner or backgrounding the app stops microphone analysis. Audio is not recorded or uploaded.
  5. For unstable readings, mute unused strings and reduce background noise. Play a steady note and test your own instrument before live use.

Device volume & buffer

  1. Open Settings → Audio & playback. Device volume in the native iPad app follows system volume and the physical volume buttons. The percentage helps compare levels between shows.
  2. Save reference level stores a reference; it does not automatically change system volume at the next launch.
  3. Choose a supported buffer size. 256 reduces latency, 512 is a middle option and 1024 allows more processing margin. Check the actual reported buffer.
  4. A lower buffer is not always better with many tracks or transposition. Test the full setup. Mac volume and available device controls may be managed by the system or interface.

MIDI & foot controls

  1. Open Settings → MIDI & pedals. Open MIDI settings and MIDI clock output are the two rows on that page.
  2. In Open MIDI settings, select the input, search the categorized action tiles, select an action and press Learn. Selecting a tile does not run its action.
  3. MIDI CLOCK OUTPUT in the native app sends the playback tempo to one selected MIDI output. Start/Stop is optional. Start from the beginning for a shared start; test the physical looper before live use.
  4. Test Play/Pause, Stop, Next, mute groups and any expression pedals before performing. Check that one pedal does not send unwanted duplicate messages. Also test Stop and song changes in fullscreen.
  5. Bluetooth and MIDI device availability depend on the platform and connection. Native provides platform integrations.

Ui24R cues

  1. Open Settings → Mixer cues & shows and link songs to the correct Ui24R show/cue. Check the connection and names before playback.
  2. Cues and audio routing are separate. A working network connection does not replace correct USB patching.
  3. A synchronized backup device does not need to output audio at the same time. Choose deliberately which device is connected to the interface.
  4. Test cue selection and audio separately before relying on the complete setup.
  5. The Ui24R connection library is built into BenKen, so it works without internet and no code is downloaded.

Device sync (live) — concert folder

  1. Open Settings → Sync & sharing → Device sync (live). This copies a concert, including audio, through a shared folder. For everyday song and setlist changes, use Autosync instead.
  2. Choose the concert setlist and a shared sync folder accessible on both devices. The folder can be empty the first time.
  3. On the device with the updated concert, sync TO the folder. On the receiving device, sync FROM the same folder.
  4. Keep both apps open until transfer is complete. Check songs and audio on the receiver before using it as a backup.
  5. This transfers concert content and files. It does not provide automatic shared Play/Stop or guaranteed simultaneous playback. Automatic updates wait while music plays.

Autosync between devices

  1. Open Settings → Songs & setlists → Autosync & web editor. Sign in with the same account on iPad, iPhone and Mac and switch on Autosync on each device.
  2. Autosync keeps song details and setlists the same on all your devices: title, artist, key, lyrics and chords, notes, chord chart, original BPM, time signature, tags, bandmate capo, song colour and chord voicings, plus setlist names, order and dividers.
  3. Audio files, mixer settings and setlist cover images are not synced. Copy audio with a full backup, Share songs & setlists or Device sync (live).
  4. Sync runs when BenKen opens, a few seconds after you save, when the device comes back online or returns to BenKen, and every five minutes. It waits while a song plays or prepares, while Live lock is on, or while a dialog or the song editor is open. The status line shows the last result.
  5. Changes to different details of the same song are merged. If a song or setlist was changed on two devices at once, check it after the sync.
  6. If a sync would remove more than three songs and more than a quarter of the library, the removal is held. Press SYNC NOW to confirm it. Recovery copies of removed songs are kept on the device.
  7. The web song editor on the same page edits title, artist, key and lyrics in a browser; Autosync then brings the changes to your devices.
  8. Delete account: Settings → Songs & setlists → Profile & document details → BenKen account → Delete account, or under Autosync & web editor (when signed in). Type DELETE to confirm. It removes your BenKen account, the synced copies of songs and setlists, bands where you are the only member, and audio you uploaded for sharing or rehearsal mixes. Bands you share with others stay with them and another member becomes admin. Songs, setlists and audio on your devices are kept. It cannot be undone.

Full backup & restore

  1. Open Backup & restore and CREATE FULL BACKUP. A backup with audio may contain several parts; keep all of them.
  2. Provide all required parts when restoring. Choose ALSO RESTORE OUTPUT / MIDI / CONTROLS only if you also want the source device settings.
  3. JSON export contains songs, setlists and settings but not the audio itself. Use a full backup with audio for a complete backup device.
  4. A backup cannot include audio missing from the source device. Restore or replace missing files first and keep a known working backup.
  5. In the installed app (V27.56 or newer), songs, setlists, settings, calendar, venues and other BenKen data are copied into the app after every save, just like audio files. If the web storage is ever empty, BenKen restores this copy automatically. It does not replace a full backup on another device.

Weekly local backup

  1. Set Automatic local backup to WEEKLY for a local restore point on this device.
  2. This does not automatically create a file in iCloud or on your Mac and does not replace an external full backup.
  3. Check the latest saved copy under Backup & restore. The device needs enough storage.
  4. Before changing devices, clearing app data or making major library changes, also create a full backup with audio.

Share songs & sets with audio

  1. Open Settings → Sync & sharing → Share songs & setlists and choose a song or setlist. Check that the required audio is available locally.
  2. Cloud sharing requires a configured Supabase project and permission to upload. Only use the public project key in app configuration.
  3. After upload, share the link or QR code. The receiver downloads the content. Links use the selected expiry period.
  4. An expired link does not necessarily remove stored cloud copies. Manage cloud sharing separately from ordinary local backups.

Share lyrics & external display

  1. Open Settings → Sync & sharing → Share lyrics. Share lyrics uses host/follow to display lyrics on other devices. Configure the host and check the network.
  2. This is different from sharing a complete setlist with audio. Receiving lyrics does not mean all audio files are installed.
  3. On Mac, Settings → External display → OPEN LYRICS WINDOW opens a separate reading window. Move it to the desired display and choose text size and chord visibility.
  4. iPad can use screen mirroring. This version does not provide an independent native external-display view.

Skins, notes & information

  1. Choose a skin in Settings → Theme & colours → App skin, for example Dark, Blue & White, Studio Black or Warm Paper. Buttons in menus are filled with the skin colour. Blue & White uses a blue top bar, blue section bar and blue buttons with white text. Personal text and track colors are retained.
  2. Save notes and FX information per song and choose how they appear when opening it. FX information is text; it does not activate an audio effect.
  3. SHOW INFO toggles extra explanations in Settings. The manual and About remain available when it is off.
  4. About shows features, web/native versions and credits. Compare both versions when troubleshooting.
  5. Help & Info → Open-source licenses lists the third-party code inside BenKen (QR Code Generator, the Ui24R connection library with RxJS and tslib) with their licenses and full texts.

Offline use & updates

  1. With BenKen app V27.58 or newer, BenKen opens from web files inside the app, so it starts without internet. Builds installed from Xcode download new web versions in the background, check every file and use them the next time BenKen opens; a version that fails to start twice is skipped. The App Store version uses only the files built into the app, so updates come with new versions of the app.
  2. Settings → Audio → Storage → BenKen web files shows the running version, whether it is built in or downloaded, and a version waiting for the next start. Check for update now looks right away.
  3. Audio files must be available on the device. Inside the app, audio is played from the permanent audio copy; it is not copied again into the web storage.
  4. After the move to the app’s own address, Storage shows Old copy at the GitHub address. Remove it when your songs and audio are here to free the space it used.
  5. Publish every file in a web package together, including app-files.json. Update well before rehearsal or a concert and test the complete setlist after important changes.

Troubleshooting

  1. No sound while the timeline moves: check engine, Stereo/USB, mute, buses, system volume and physical outputs. Use a current native build.
  2. Missing audio: check song/track names, use REPLACE FILE or restore a backup with audio. A filename in a JSON backup does not contain the file.
  3. No tuner reading: check microphone permission, play one clear note and move away from speakers or noise. Update the native app if needed.
  4. If the web page process stops, reopen the app and note the preceding import, song or action. Keep a known working backup and test fewer changes at once.

Report a problem

  1. Open Settings → Help & Info → Report a problem. Choose the area, write a short summary, what happened and what you expected, and the steps if you know them. The current song and your sign-in email are filled in; change or clear them as you like.
  2. Attach Audio Status adds versions, the audio device and outputs, MIDI Clock state, prepared tracks and recent error messages. SHOW WHAT IS SENT shows the exact report before you send it. Lyrics, audio files and your library are never sent.
  3. SEND REPORT sends it straight to the developer. Without internet the report is saved on the device and sent automatically later. You can send without signing in; deleting your account also deletes the reports you sent while signed in.

Calendar — rehearsals & concerts

  1. Open Settings → Planning → Calendar. Venues and Packing list are in the same group.
  2. The month view works like Apple Calendar: concerts and rehearsals are shown inside their date. iPad and Mac show the names (two per day, then +1, +2 …); iPhone shows coloured dots. Concerts use the skin colour and rehearsals blue (green in Blue & White). Today has a round marker.
  3. Use the arrow buttons beside the month name to change month. Tap a date to see only that day’s events with SETLIST, SONG, Edit, Packing list, .ics, Contract draft and Remove. CLOSE returns to the month. Without a selected date, the page only shows how many events the month has.
  4. ADD EVENT creates a rehearsal or concert. Enter title, start/end dates and times, plus arrival and soundcheck if needed. Use the following end date for events crossing midnight.
  5. Select a venue, setlists and individual songs. SAVE EVENT stores the event. Local calendar data is included in a full library backup. Share an event through Band & planning to publish it to members; local saving alone does not publish it.

Venues

  1. Open Settings → Venues. ADD VENUE stores name, address, postcode, city, country, contact, phone, email, website and stage notes.
  2. Search Apple Maps is the framed field at the top. Type the venue name and city; matches appear while you type (or press SEARCH / Enter). Tap a match to fill in name, address, post code, city and country, then check the details and save.
  3. Address search needs the installed BenKen app. In a browser, OPEN APPLE MAPS opens a normal map search. If Apple Maps reports an error or finds nothing, the message is shown under the field; add the city or fill in the address yourself.
  4. Save a venue before assigning it to an event. Reuse a venue for multiple rehearsals and concerts. EDIT changes details. REMOVE removes the venue and clears linked event venue selections; the events themselves remain.
  5. MAP / DIRECTIONS opens the saved address in Maps. Calendar export includes venue name and address, not automatically the contact, phone or contract fee.

Packing lists

  1. Open PACKING LIST from Calendar. Choose an event or edit Default packing template.
  2. The template is copied to each new event. Changing it does not rewrite existing event packing lists.
  3. Add items and adjust quantities with plus/minus. EDIT LIST lets you rename or remove equipment. DONE EDITING returns to the checklist. Use clear names for cables, spares and chargers.
  4. PACK FOR THE GIG and BRING HOME use separate check marks. An item can be packed without being marked as returned.
  5. Local packing lists stay on this device unless shared through a published band event.
  6. Edit item names and who brings them, then SAVE LIST. Band administrators can edit the responsibility on shared items.

Contract drafts

  1. Open an event, choose EDIT and enable Create contract. Enter organizer, contact, fee, currency, any VAT text, payment and performance details.
  2. Optionally enter two cancellation tiers with percentages and days, plus additional terms. Example percentages and deadlines are not automatically binding conditions.
  3. Choose practical agreements for transport, PA/lighting, loading help, dressing room, catering, guest list, rights, marketing and accommodation. Use Other conditions for details.
  4. SAVE EVENT stores the draft. CONTRACT DRAFT exports an HTML document with the details and signature fields. Open it and print/save as PDF if needed.
  5. BenKen does not automatically send or sign the contract. Review the details and agreements before sharing.

Apple & Google Calendar

  1. EXPORT CALENDAR (.ICS) exports all events. The .ICS button on one event exports only that event.
  2. Import the file into Apple Calendar on Mac or Google Calendar on a computer. Export converts times from the device’s local time zone.
  3. In the installed app, open Apple / iOS Calendar, choose CONNECT CALENDAR, grant access and select a target calendar. SYNC NOW adds or updates BenKen events. Update automatically runs after saving; deleting in BenKen removes the linked calendar copy.
  4. The connection is one-way from BenKen. Changes made in Calendar are not imported back. A Google calendar must be added to the device’s Calendar and writable to be selected. Band membership and calendar access are separate; .ICS remains a manual export.

Microphone permission

  1. Use a current native app. Opening Tuner starts the permission request and analysis; no separate Start button is needed.
  2. On iPad/iPhone, check Settings → Privacy & Security → Microphone. If BenKen is listed, enable access. It must request access before it appears in that list.
  3. The native tuner uses the device’s microphone input. On iPad the built-in microphone is preferred when available.
  4. Close the tuner before returning to playback. Analysis also stops on backgrounding, navigation or playback start.

Section bar & large live buttons

  1. Enable Show sections under Controls → Playback & lyrics or the corresponding Lyrics option. The upper bar shows current and next sections using REAPER regions or saved Sync lyrics timing.
  2. Enable Large live buttons under Control bar & side shortcuts. LIVE · PLAY & NEXT enables this view without replacing your Available buttons. Save the setting. Switch it off and save to return to your own buttons.
  3. Live buttons can be placed at the bottom or vertically on either side. Vertical buttons use the ordinary side-button size and sit below the header and section bar.

Palettes, region colors & controls

  1. Theme & colours → Color palettes applies coordinated text, chord, section and metronome flash colors. This replaces Personalization colors; ordinary skin changes retain them. Track colors are retained.
  2. Imported REAPER colors are used when Personalization override is off. The section bar follows the same region color choice.
  3. Under Available buttons, Metro flash toggles the flash, Sections toggles the section bar, and Capo & Key opens the key/capo editor. Tuner is another available action.

All Controls settings

  1. Settings → Buttons & fullscreen and the Controls settings shortcut open the same menu. Choose placement, size, buttons and fullscreen options there.
  2. Playback & lyrics contains Show sections directly above Show waveform. Show sections controls the upper section bar independently of the waveform. Use SAVE CONTROLS.
  3. Control bar & side shortcuts opens directly, without another expandable Control bar step. When opened from Settings, use Back to Settings to return.
  4. When the setlist or library is open, the left Metronome, Tuner and Capo & Key shortcuts hide. The Setlist button remains visible; closing the list restores your selected shortcuts.

Background playback & MIDI Clock

  1. Use a current native build over the existing app and matching web files. Select Native under Audio & playback. Start the song before switching to Mixing Station. Do not force-close BenKen from the app switcher.
  2. Under Settings → MIDI & pedals → MIDI CLOCK OUTPUT, select an output, enable Send MIDI Clock and save while playback is stopped. These settings belong to this device.
  3. Clock follows playback tempo at 24 pulses per quarter note. Start/Stop is optional; START aligns to the first beat after count-in. Start at the beginning to align a looper with backing tracks. Seeking/resuming does not reposition the looper.
  4. Test clock/audio with the actual MIDI device and hub. Disconnecting MIDI stops clock but not the audio tracks. Audio interruptions and actual output-device changes can stop playback. Automatic next-song playback in the background is not confirmed.

Song Loudness

  1. Open Settings → Song loudness or SONG LOUDNESS near Song Master. Stop playback and wait for preparation to finish.
  2. Choose a target such as −14 LUFS. ANALYZE & APPLY measures the current song. To do a whole set, choose the setlist in the Setlist field and press ANALYZE SETLIST; the setlist does not have to be open first. Progress shows the current song, file and overall completion.
  3. Adjustment is stored per song without changing original audio. Peaks or the maximum allowed gain can limit the target. Click and cue may be excluded under Tracks & measurement.
  4. The measurement is a stereo reference at original tempo, before EQ, compression and global master gain. It does not guarantee perceived live loudness or true-peak level.
  5. RESET SONG restores the Song Master level from before normalization. If analysis is cancelled, already processed songs are retained.

Storage — free up space

  1. Open Settings → Audio → Storage. It shows free space on the device, the total BenKen uses and each part: audio in the web storage, the permanent audio copy in the app, the library copy, the playback cache, the saved native concert and temporary files. Measure again updates the numbers.
  2. Audio is kept twice on purpose: the web storage holds the working copy and the app keeps a permanent safety copy that restores audio if the web storage is emptied. Do not expect to halve this; it protects your library.
  3. Remove prepared copies removes the prepared audio of the saved native concert from Device sync (live). The concert itself is kept and the copies are made again when needed. Clear temporary files removes leftovers from imports and preparation. The playback cache is cleared under Audio & playback → Clear cache.
  4. Audio no song uses lists files left after deleting songs or tracks. Remove unused audio deletes them from both the web storage and the app copy; audio kept for the weekly local backup stays. Songs, setlists and audio in use are never removed. Make a full backup before big clean-ups.
  5. Stop playback and wait for audio loading before cleaning. The app’s own folders and free space need BenKen app V27.57 or newer; in a browser only the unused audio can be checked.

Automatic local audio cache

  1. Requires the installed app and the Native audio engine. All imported songs are prepared on this device after 15 seconds without interaction, with playback stopped. The app must stay open and visible. No setlist selection or preparation button is needed.
  2. Playing a song or interacting with the app pauses background preparation. It resumes while idle. The first preparation takes time and uses device storage. Missing audio must be imported first.
  3. Prepared audio and verified playback copies stay on this device and can be reused after reopening the app. New or changed files, tempo, key or track settings may require preparation again.
  4. Open Settings → Audio & playback → Clear cache to remove disposable native playback copies with playback stopped. Imported original audio, songs, setlists, settings and saved concert libraries are preserved. Copies rebuild automatically while idle; the current song is reloaded immediately.
  5. Playback is not gapless. Test your actual device, output and set before a show.

Use original tempo & key

  1. Stop playback and open Settings → Tempo & metronome. Enable Use original tempo & key at the top. The song is prepared again using original tempo and zero audio transpose.
  2. The choice is saved for this song. Saved target BPM and transpose remain unchanged. Turn the choice off to prepare using those adjustments again.
  3. This can reduce new processing for songs with changed tempo or key. It does not skip reading original files or output setup. Already cached audio may show little difference, and songs already at original settings gain no additional speed.
  4. The metronome follows the original BPM when Follow song playback BPM is enabled. Lyrics and section timing follow the active playback settings; manual chord-view and capo choices remain available.

Native track EQ

  1. Requires the installed app with the Native audio engine. Open Mixer and tap FX · EQ on a track, or use Mixer settings → Track EQ.
  2. Enable EQ to hear the low shelf, two parametric mid bands and high shelf. Use the curve or knobs for frequency and gain; the mid bands also have width controls.
  3. EQ is saved per song track and applies before output routing in Stereo and Live / USB. Changes do not require new audio preparation. Reset turns EQ off and restores neutral settings.
  4. Positive EQ boosts increase output level. Check headroom and sound before performing. Browser and Native use different filter implementations, so their exact responses can differ.
  5. Physical device and interface testing is still required.

Packing list views & export

  1. Open Settings → Packing list. Choose the default template or an event. Switch between LIST and CARDS; the view is remembered on this device.
  2. Edit names, quantities and items using EDIT LIST. Event checkmarks are separate for Pack for the gig and Bring home.
  3. EXPORT PDF saves the selected list with quantities and the current packing/return checkmarks. EXPORT CSV includes quantities and both checkmark columns. Your contracts and private contact details are not exported.

Chord diagrams & text fonts

  1. Settings → Chord diagrams: enable diagrams and choose Guitar, Piano or Guitar & Piano. Position and size are separate choices.
  2. Supports major, minor, suspended, diminished, augmented, sixths, sevenths, ninths, elevenths, thirteenths and selected altered families in all twelve roots. maj7/maj9 and dom7/dom9 are recognised, including sharp/flat roots and slash bass. Unsupported spellings are labelled instead of guessed.
  3. Guitar voicings are checked against chord tones. Choose a comfortable shape. For thirteen chords, guitar may omit the fifth and eleventh; piano shows all chord tones.
  4. Settings → Fonts & text: choose System Mono, Courier or Menlo / Consolas and enable Bold lyrics. The monospaced fonts keep chord labels aligned with the words. Font availability depends on the device.

Choose buttons in Controls

  1. Open Settings → Buttons & fullscreen → Available buttons. Choose a category or search for a button. Press a tile to add it; press a selected tile to remove it. The number shows its position.
  2. Open Your buttons to change the order with arrows or add an optional label. SAVE CONTROLS applies the selection. Closing without saving keeps the previous selection. Large live buttons remains a separate temporary Play / Next view.
  3. Add Lyrics / Chords / Both from the Lyrics & display category. Press the control to cycle Both → Lyrics → Chords → Both. This changes the reading view only, without changing audio, song key or either capo.

Track names, waveform and metronome

  2. Turning waveform off hides its seek strip, buttons and time labels. Enable Show waveform in Controls settings to restore it. Sync Lyrics remains under Scrolling & sync.
  3. The Metronome button in Controls and the left shortcut switch the click on and off directly. Select and prepare a song first. The saved metronome bus, sound, BPM and level are used. STOP also stops the click.

Import lyrics for multiple songs

  1. Open Settings → Import songs & projects → Lyrics / ChordPro. Select a BenKen lyrics collection (.json, .txt or .benkenlyrics), or several ChordPro/text files. Extract ZIP files in Files first.
  2. Review each destination: matching titles select existing songs, unmatched titles create new songs, and ambiguous matches are skipped until you choose an existing song or Create new song. Preview and edit the text before importing.
  3. Existing songs keep their audio, routing, setlists, key, chord chart and timing; only lyrics change. Check timing and chart alignment afterwards. A text-library backup downloads before existing lyrics are updated.
