Audio test and Ui24R USB routing

New backing tracks use bus 1 → stereo USB 1–2. Click tracks use bus 2 → mono USB 3. Older songs may route directly to USB. CONNECT DIRECT TRACKS TO BUSES preserves their USB outputs and levels.

Output numbers are USB DAW channels. On the Ui24R: Settings → Patching → Channels → USB DAW 1–16 / 17–32. Patch the returns to free mixer channels. Playback is blocked when outputs are missing. Stereo practice also sends the click to outputs 1–2.

Faders range from off to +6 dB. 0 dB keeps the original level. Press 0 / 0 dB or double-tap a fader to reset it to 0 dB. Muted tracks also count towards the memory limit.
